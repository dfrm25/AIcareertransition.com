This Week in AI

Copilot gets business context

Work IQ adds Dynamics 365 data, a new Copilot app, and three new models. Official sources, one try-this each.

This week's updates

This site is for people who already have a job. Goal: dated proof of work you can show a manager in 30–90 days. Not a job board. Not a degree catalog.

What this brief is, and what it is not

This is

  • A dated reading of official OpenAI, Google, Anthropic, and Microsoft posts
  • One concrete work action per item, with an internal page to do it

What changed (since September 21)

Copilot is getting business context and more model choice. Work IQ adds Dynamics 365 and Power Platform data. The Copilot app gets Home, Code, and Autopilot. Claude Opus 5.5 and GPT-6 Sol ship and start rolling into Copilot. Pick one. You stay the check.

Microsoft · Sep 25, 2026 (preview starts Sep 30)

Work IQ now reads your business data

Work IQ grounds Copilot and agents in Dynamics 365 and Power Platform data alongside your Microsoft 365 context, in public preview starting September 30, 2026, with rollout continuing through October. Source

Try this: Write down one question you answer every week by stitching two systems together, such as CRM plus email, and save it as your test prompt for when the preview reaches your org. Go

Microsoft · Sep 25, 2026

New Copilot app: Home, Code, Autopilot

Microsoft introduced a new Copilot app where Home joins Chat and Cowork, Code builds small apps and trackers from plain language, and Autopilot is a persistent agent. Home and Code roll out to the Frontier program in the coming weeks; Autopilot expands to private preview at the end of September. Source

Try this: List one tracker or checklist you still update by hand each week; that is your first build candidate when Code reaches your tenant. Go

Anthropic · Sep 22, 2026

Claude Opus 5.5: clearer writing, lower cost

Anthropic released Claude Opus 5.5, which it says performs at Claude Fable 5.1 level on most work, writes more clearly, and costs 40% less to run than Opus 5. Microsoft began rolling it out in Copilot the same day. Source · Copilot rollout

Try this: Run one draft you own through your usual model and through Opus 5.5 (in Claude, or the Copilot model menu if it appears), then keep the version that needed fewer fixes. Go

OpenAI · Sep 22, 2026

GPT-6 Sol and Luna reach ChatGPT Work

OpenAI released GPT-6 Sol for complex work and GPT-6 Luna for high-volume tasks in ChatGPT Work and Codex for Plus, Pro, Business, Enterprise, and Edu users, with API prices 50% lower than GPT-5.6. GPT-6 Sol is also rolling out in Microsoft Copilot. Source · Copilot rollout

Try this: Give the same file to the lighter model for a summary and the stronger model for an analysis, and note which task actually needed the stronger one. Go

Google · Sep 22, 2026

Gemini study notebooks come to work accounts

Gemini study notebooks, which turn sources you upload into short lessons, quizzes, and a progress dashboard, are now available on work and school Google accounts when an admin has the Gemini app and Gemini Notebook turned on. Source

Try this: On an approved work account, upload one guide you need to learn and ask for a five-question quiz, then check every answer against the source. Go

Meta · Sep 23, 2026

Muse for Mac can now run your apps

With your permission, Meta's Muse agent can now operate any app on a Mac and keep working while you step away. Muse on Meta's AI glasses is coming in the next few months. Source

Try this: Before letting any agent click through work apps, check your company's AI policy, and test it on a low-stakes personal task first.

Tip

Auto picks the model. Work IQ picks the context.

Microsoft says Auto weighs accuracy, speed, and cost on each request to choose a model. Work IQ is a separate on/off switch for whether Copilot reads your work data. Set both on purpose before a hard task.
