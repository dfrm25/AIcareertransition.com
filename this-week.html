What changed (since September 14)

Reviewed September 21, 2026. Models you already know (Fable 5.1, Gemini 3.8 Flash, GPT-6 Astra, Astra in Copilot) are still the default pickers. This week’s official drops are agent harnesses and live voice surfaces — use them on one owned task, with you as the gate.

OpenAI Agents API (public beta) — September 10, 2026

OpenAI launched the Agents API in public beta: the Codex harness, hosted by OpenAI, for building and running cloud agents. Choose compute (OpenAI-managed sandbox, your infra, or a partner). No separate API fee beyond tokens and tools. Harness logic is inspectable via the open Codex codebase. Source

Do this: This is for a governed agent on one workflow — not unsupervised mail or production writes. Pick one owned process, keep a human verify step, save the transcript as proof. Go

GPT-Live-1 in the API — September 10, 2026

GPT-Live-1 brings full-duplex voice (listen and speak at once) to the API for voice-enabled apps and workflows. Priced as a front-end voice layer; pair with your backend model / agent harness. Also referenced with OpenAI Presence for enterprise voice agents that escalate to people. Source

Do this: Only if your product or support lane already needs voice. Prototype on a non-customer script first; escalate path required before any live guest path. Go

Gemini 3.8 Live & Live Extended Thinking — September 15, 2026

Google introduced Gemini 3.8 Live (fluid dialogue + visual grounding) and Gemini 3.8 Live Extended Thinking (higher complexity, multi-step while conversation continues). Rolling to Gemini API / AI Studio; enterprise private preview; consumer Gemini Live / Search Live paths per plan. Source

Do this: If you already use Gemini Live or Workspace voice, this is the upgrade path — still one owned task, checked line saved. Confirm your admin / plan before you demo. Go

Tip

Keep a human gate

Agent and voice loops stop before send / write to production. Initials + date on the check. Proof line: “Ran X on Y task; verified Z; artifact here.” One sentence you can show a manager.

Career path

Proof move

One surface, one artifact

Agents API or Gemini Live or Copilot /app — not all three. Switching mid-proof wastes the week. Pick one: Agents API / Codex-style harness on a redacted internal FAQ draft (human merge only), or Gemini 3.8 Live (or Live Extended Thinking) to walk an owned doc while you verify citations, or Copilot /app only if Frontier/Studio is already on — scaffold one process app, do not ship without review. Save the checked artifact. That is the week.
