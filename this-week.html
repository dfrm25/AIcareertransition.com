What changed

Reviewed August 29, 2026. Full write-up: Verify before you ship.

The study is about review, not about ChatGPT replacing you

OpenAI published a randomized study of more than 1,000 students on ChatGPT, critical-thinking training, originality, and a real university assignment. We are not reprinting their results here. The career signal is the design: the interesting condition is AI plus a review habit, not AI as a substitute for judgment. Source

Do this: On one real work draft this week, add a written line for what you checked against a source before anyone else sees it. Go

Gemini Notebook can now bind sources you already own

Google launched Expert Intelligence in Gemini Notebook on August 27, 2026. You can add select ebooks you purchased on Google Play Books and ask questions that cite those pages. A day later Google said consumer usage limits become compute-specific, refresh every five hours, and start rolling out September 2. Source · Limits

Do this: Put one owned source (a brief, a policy, or a book you actually have) into a notebook and ask a question that must quote it. Go

Codex stories are proof-of-work, if you keep the review step

OpenAI published a loveholidays customer story on August 26 about using Codex so more people inside the company can turn ideas into working software. Treat it as a vendor case study, not a salary forecast. The usable pattern is: a coding agent on a small internal tool, plus a human who can explain what shipped. Source

Do this: If you already have a coding agent at work, document one small tool you shipped this month with the check you ran before it went live. Go

Copilot agents are still the Microsoft 365 path

Microsoft's current docs still describe agents as the way to extend Microsoft 365 Copilot with extra knowledge and actions (summaries, mail, record updates). Declarative agents use Copilot's orchestrator; custom-engine agents bring your own. Admin approval is not optional if the agent can send anything. Source

Do this: If you have Copilot, write instructions for one recurring task you already own and require a human step before send. Go
