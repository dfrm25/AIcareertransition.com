Agents Official source

Agent-building moves from experimental to standard tooling

Every major lab now ships first-party ways to build and run multi-step agents: OpenAI's AgentKit, Google's Vertex AI Agent Builder, Anthropic's tool use & MCP, and Microsoft's Copilot Studio & Agent 365.

Career action: Read the multi-agent workflow guide and ship one supervised researcher→drafter→reviewer flow as a proof artifact.

Models Official source

Reasoning / "thinking" modes are the default for hard work

The flagship families all expose adjustable reasoning effort or extended thinking. Check the live capability pages rather than memorizing version numbers: OpenAI models, Gemini models, Claude models.

Career action: Learn when to switch to thinking mode with our reasoning models guide.
