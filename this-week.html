Google

Oct 8, 2026

Gemini agent is a universal agent for work

On 8 October 2026, Google Cloud announced the Gemini agent and called it a universal agent for work. One prompt box carries the organization's business context. It plans the work, uses skills and tools, and connects to Cloud customers' business systems. It brings finished work back inside documents, the inbox, and developer environments. It picks the best model for the job, with built-in cost controls and enterprise security, admin, and governance.

Claude works in Docs, Sheets, and Slides

Claude for Google Workspace is in public beta on all paid Claude plans. Claude works inside Docs, Sheets, and Slides. Beta Docs, Sheets, and Slides connectors also let Claude create and edit those files from chat.

Google

Sep 30, 2026

Gemini 4 Argon is limited access

Google announced Gemini 4 Argon on 30 September 2026 and is rolling it out to a set of trusted cyber defenders through the Fairwind Program, not as a general release. Broader access starts later with paid API customers and Google AI Ultra subscribers.

Anthropic

Sep 28, 2026

Claude Sonnet 5.5 is for scoped work

Anthropic released Sonnet 5.5 on 28 September 2026 as a faster, lower-cost complement to Opus 5.5 for well-scoped tasks such as bugs, documents, slides, and spreadsheets. In Claude Code and Anthropic's apps, the default effort is Medium.

Try this:

Move one well-scoped task you already own onto Sonnet 5.5 before you spend Opus on it. Go

Source Go
Anthropic

Claude Code aliases now point at 5.5

On the Anthropic API, opus resolves to Opus 5.5 and sonnet resolves to Sonnet 5.5. Claude Platform on AWS still resolves sonnet to Sonnet 4.6. Bedrock and Google Cloud Agent Platform resolve it to Sonnet 4.5. Microsoft Foundry resolves opus to Opus 4.6 and sonnet to Sonnet 4.5. Sonnet 5.5 needs Claude Code v2.1.284 or later, and Opus 5.5 needs v2.1.280 or later.

Try this:

Check which alias your session resolves. If a 5.5 request fails, update Claude Code before you brief a long task. Go

OpenAI

ChatGPT dots keep working between chats

OpenAI describes dots as always-on agents in ChatGPT that take ongoing work and keep going between conversations. You set a goal, connect the apps, and define what the dot may do on its own. Rollout is gradual for eligible Pro and Business Premium users aged 18 or older. Pro excludes the EEA, Switzerland, and the UK at launch, and Enterprise is a beta that is off by default.

Work IQ business data is in preview

Microsoft's 25 September 2026 post says Work IQ now grounds Copilot and agents in Dynamics 365 and Power Platform data, plus Microsoft 365 context. The preview started 30 September 2026 and continues through October. Governed actions stay inside the user's permissions and can require approval.
