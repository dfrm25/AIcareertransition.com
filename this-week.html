This Week in AI

What shipped this week from OpenAI, Anthropic, Google, and Microsoft, plus one thing to do with it.

This week's updates

What changed

GPT-5.6 is now the default model in ChatGPT

On August 6, OpenAI made GPT-5.6 Luna the default for Free and Go users, with a Think button for harder questions and unlimited text chats. Plus and Pro get GPT-5.6 Sol with a reasoning slider. OpenAI announcement

Do this: Open the model picker. If you still see Auto, switch to Sol (or Luna + Think) for anything you would send to a manager. Then save one before/after in your notes. Where the picker lives

Claude Opus 5 and Sonnet 5 are agent models

Opus 5 (July 24) is Anthropic's default on Max for long-running coding and knowledge work. Sonnet 5 is the Free/Pro default and is built to plan, use a browser and terminal, and run on its own. Opus 5 · Sonnet 5

Do this: Brief Claude as an agent, not a chatbot. Give it a goal, tools, a stop condition, and a review step. Start with the agentic prompts.

Copilot Agent Builder is how workplace agents ship

Microsoft's Agent Builder now turns capabilities on by default for new agents. Late August rollout. If you work in Microsoft 365, this is the path that will show up in your org's agent store. Agents overview

Do this: Pick one recurring task (status email, file summary, meeting follow-up) and sketch the agent instructions plus the human approval point. How to supervise an agent

Prompt of the week

You are an agent, not a chatbot. Goal: [TASK]. Context I am attaching: [FILES OR NOTES]. Tools you may use: [SEARCH / CODE / BROWSER / NONE]. Constraints: do not invent numbers; stop and ask if a source is missing. Work in this loop: plan, act, check, then give me (1) the deliverable, (2) what you did, (3) what a human must verify before this ships.
