Workplace AI SOPs

A guide on this site is a workplace procedure you can run on a real packet: schema, rubric, human gate, and a 30-day matrix. It is not a course catalog, not a university syllabus, and not a list of 101 or 201 modules.

What this index is, and what it is not

This is

  • A directory of original workplace SOPs for people who already have a job
  • The Product Manager PRD review as the flagship
  • Pointers to the career path, Excel checks, and model picker

This is not

  • A university, degree, or certificate mill
  • A job board or a salary forecast

Flagship SOP

Product is written first because a PRD is a packet you can bind, score, and show. Other roles will get the same shape when they are written. We do not invent a second SOP to fill this page.

Product Manager PRD review

Four steps: bind a packet, run a dual-model review, human-gate P0s, then ship with cycle-time notes. Includes a JSON schema, a 16-point rubric, and an L2 to L4 30-day matrix a hiring manager can check.

30-90 day career path

Pick a lane next to your current job, build one artifact, then rewrite the resume story. Use this after you have run one SOP once.

Use these with the SOP, not instead of it

A procedure without a check is a prompt list. These pages are the checks we already published. They stay indexed because they are original work, not filler.

What AI gets wrong in Excel

Unread tabs, cross-sheet formulas, and the human checks that keep a bad number off a slide.

Where to change the model

Text steps for Copilot, ChatGPT, Claude, and Gemini. Pick a default, then switch when the work is high-stakes.

Monday reports

A recurring weekly write-up you can actually run. Name the source, the check, and the decision.

Knowledge-work survey

Wave 1 is fielding. Methodology first. No pre-filled percentages and no invented cohort stats.

How to use a guide this week

  1. Open the PM SOP if you own a spec, or the career path if you do not.
  2. Bind one real packet you already have. Do not invent a side project.
  3. Write down what you checked before anyone else sees the output.
  4. If you need a paste-ready prompt, use the prompt library after the SOP, not as a substitute.
